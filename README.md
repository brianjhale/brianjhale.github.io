# Brian Hale — Developer Portfolio

Personal developer portfolio hosted on GitHub Pages, featuring automated project synchronization across personal repositories and organization projects (`native-state-tools`).

🚀 **Live Website:** [brianjhale.github.io](https://brianjhale.github.io)

---

## 🛠️ Features & Architecture

* **Zero Build Step:** Built with pure static HTML5, CSS3, and modern Vanilla JavaScript (`ES6+`).
* **Automated Syncing:** Uses the GitHub REST API to dynamically fetch, parse, and render repositories from both `@brianjhale` and `@native-state-tools`.
* **Local Storage Caching:** Features client-side `localStorage` caching to minimize API calls and prevent rate-limiting during local development.
* **Responsive Layout:** CSS Grid architecture designed for seamless viewing across mobile, tablet, and desktop viewports.
